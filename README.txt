ERP HTML Lessons Landing Page
=================================

READY FOR GITHUB PAGES
- Upload every file and folder in this package to the repository root.
- Keep index.html in the root.
- GitHub Pages will use index.html as the landing page.

SEQUENTIALLY RENAMED LESSON FILES
- lesson-01.html : Week 1, Sessions 1-2 - Introduction to ERP and Its Evolution
- lesson-02.html : Week 2, Session 3 - ERP Architecture
- lesson-03.html : Week 2, Session 4 - Core ERP Modules

LOCKED / UNAVAILABLE LESSONS
The landing page currently displays 36 lesson slots. Lessons 04-36 are marked
Unavailable because their HTML files were not included in the uploaded package.

ADDING THE NEXT LESSON
1. Name the next file lesson-04.html.
2. Open index.html in a text editor.
3. Add Lesson 4 inside the availableLessons object using the same format as Lessons 1-3.
4. Upload the updated index.html and lesson-04.html.

TEACHER RESOURCES
The original teacher scripts were preserved in teacher-resources/. They are not
linked from the student landing page.

No external libraries, online fonts, or APIs are required.
